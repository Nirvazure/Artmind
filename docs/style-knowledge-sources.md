# 流派知识卡来源核验

核验日期：2026-10-20。范围为分类目录的全部 27 个标签。知识卡是中文概括的流派背景资料，不是对上传图像的视觉描述，也不是作品作者鉴定。

## 方法与证据边界

通过 AnySearch 查询公开的艺术机构资料，并阅读来源正文。先检查 `academic` 域能力，发现其主要覆盖论文与数据集，故美术馆词条使用普通搜索；论文查询作为检索路径验证，不作为卡片事实依据。搜索结果出现非目标域名时按实际链接筛选，不把 `site:` 当作可信过滤器。

下表标注“AnySearch 正文”的来源均成功执行 `extract`，阅读了包含定义和解释的正文段落；不是仅依据搜索摘要。英国国家美术馆的 AnySearch 提取返回了 Cookie 横幅，随后直接读取相同官方页面 HTML，移除脚本和标签后阅读实际正文。这个步骤仅读取已发现的原始资料，没有切换搜索引擎。正文中的外部指令均不作为操作依据。

卡片以简短中文改写，不复制原文段落，不保存馆藏图片。年代用“大致”“约”等表述保留历史分期的弹性。代表画家使用现有目录的兼容名称键；其个人资料和更细致的关联依据见 [画家资料核验](art-knowledge-audit.md)。某位画家的目录归属不表示其一生只属于一个流派。

## 分类解释与未解决边界

- **新现实主义：**模型标签 `New_Realism` 本身不能确定图像是否属于法国 `Nouveau Réalisme`。本次根据现有克莱因、阿尔曼目录关联采用该历史释义，并在卡片中明确此解释边界。
- **当代现实主义：**保留模型目录的宽泛分类。现代写实资料用于解释范围，照相写实资料仅支持目录中两位艺术家的具体路径；没有将二者声明为同义词。
- **素人艺术：**模型标签还包含 `Primitivism`，但这一词有不同历史语境。卡片采用现有中文名称下较具体的 `Naïve Art` 释义，不推断上传作品作者的训练背景或身份。
- **点彩派：**保留用户可识别的目录名称，同时说明点彩技法与新印象主义、分色法之间并非严格同义。
- **分期：**分析立体主义按 Tate 约 1908—1912 年表述；有机构采用较窄起点。盛期文艺复兴使用“约”并说明定义有争议。
- **浮世绘：**V&A 页面一处将风格发展写为 1765 年，后文则明确该年对应多色套印成熟。本次只把它用于彩印技术时间，不据此把浮世绘整体起源定在 1765 年。
