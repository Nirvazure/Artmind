# 画家资料核验

核验日期：2026-10-20。审查范围为现有画家目录的全部 53 条记录。流派关联提供学习线索，不用于判断上传作品的作者，也不表示艺术家一生只属于一个运动。

## 核验方式与状态含义

通过 AnySearch 检索公开的艺术机构资料并提取正文，逐项核对名字、年代、简介和目录关联。英国国家美术馆部分页面的 AnySearch 提取只有 Cookie 提示，改为读取同一官方页面的 HTML 正文。研究过程中遇到的网络权限失败及 404 不作为证据；改用成功读取的实际页面。不会仅凭搜索摘要或页面能打开就标记已核验。

AnySearch 后续返回额度耗尽。补充波提切利、米勒、卡拉瓦乔和委拉斯开兹的流派关联时，使用网页工具阅读 V&A 与大都会博物馆的官方正文，作为明确运动语境的交叉依据：V&A 的早期文艺复兴课程目录提及波提切利；Met 法国现实主义论文讨论米勒及其与库尔贝的差异；卡拉瓦乔论文说明卡拉瓦乔主义是巴洛克绘画的重要基础；委拉斯开兹展览页将其公爵肖像置于巴洛克肖像画语境。课程与展览页面仅用于关联证据，个人年代和生平以英国国家美术馆档案为主。

穆夏与莫罗起初缺少可读的个人传记，暂未标记已核验；随后通过网页工具阅读穆夏基金会与 Thyssen 博物馆的官方正文，补齐生卒年及相关实践，再更新核验结论。逐条核验说明与来源随资料保存于数据库；研究原始清单另存于不纳入 Git 的本机迁移备份。斯特拉的 Tate 页面标题尚未更新死亡年份，已用惠特尼博物馆的 1936—2024 年交叉校正。克莱因、阿尔曼仅采用本轮实际支持的世纪年代，不推定未读取的完整生卒年。

`verified: true` 表示来源正文足以支持本目录展示的事实和经过限定的流派关系；并非对画家全部生平的认证。`verified: false` 表示已完成审查，但仍有具体证据缺口，界面通过 `verificationNote` 说明。`verifiedAt` 是此次审查日期，包括尚待补证的记录，不代表待核验资料已被确认。

中文展示名是项目采用的常见译名编辑规范，并不声称英文机构页面认证了唯一中文译法。原有 `name` 全部保留为历史匹配键，修正写入 `displayName`，无需迁移已保存作品。

## 重要修正

- 将委拉斯开兹由“现实主义”改为“巴洛克”。目录的“现实主义”指 19 世纪历史运动，不能因为一位 17 世纪画家具有写实倾向而把他编入该运动；历史保存结果不改写。
- 将笼统的世纪年代改为来源支持的生卒年或活动年代。提香出生年仍不确定，英国国家美术馆采用“约 1506 年开始活动，1576 年去世”；凡·艾克保留“1422 年已有活动记录，1441 年去世”；马萨乔保留“1401—1428/1429？”的不确定性。
- 规范“安迪霍沃尔”为“安迪·沃霍尔”等展示名，原键不变。删除“现代绘画之父”“出神入化”等不便核查的评价，以及高更简介中将其作品简化为“原始”的表述。
- 运动、时期与技法有不同边界。德加参加印象派展览但保有独立路径；修拉与西涅克的点彩技法属于新印象主义语境；当代现实主义是项目宽泛标签，并不与照相写实主义完全等同。跨流派和争议关系逐条写入说明。

## 审查与迁移结论

本轮共审查 53 条，已核验 53 条，待补证 0 条。已核验仅覆盖资料中保留的有限表述；未确认的完整生卒年等内容未作推定。逐条正文、目录关联、来源与核验说明以 Supabase 当前记录为准，文档不再复制完整目录。

2026-10-20，27 张流派卡、53 条画家资料、15 条头像引用及 61 条代表关系迁入 `artmind` schema。数据库已与 Git 忽略的迁移清单逐字段比较一致；旧名称键与顺序保留，头像沿用既有 Storage 对象。完整备份和生成的导入 SQL 不纳入版本管理。维护与验收见 [数据库迁移说明](art-knowledge-migration.md)。

## 维护与边界

- 更新资料时重新阅读实际来源正文，核对支持范围，再更新核验日期。链接可访问不等于正文仍支持现有表述。
- 原有 53 个 `name` 匹配键均保留。新增或调整目录关联只影响之后的目录推荐，不追溯改写用户保存的作者字段。
- 头像另见 [画家头像来源与存储记录](painter-portraits.md)。肖像来源、使用许可与生平资料是不同证据，不能用可下载头像代替史实核验。
- 流派卡的取舍和来源见 [流派知识卡来源核验](style-knowledge-sources.md)；馆藏代表作入口留在 [待办](TODO.md)，本次不接入作品馆藏检索。
